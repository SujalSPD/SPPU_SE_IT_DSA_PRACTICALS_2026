
# SPPU Second Year IT – Data Structures and Algorithms Practicals

This repository contains the practical assignments for the **Data Structures and Algorithms (DSA)** laboratory of Second Year Information Technology under Savitribai Phule Pune University (SPPU).

## Technologies Used
- C++
- Python

## Practical List

### Part A – C++

| No. | Practical | File |
|---|---|---|
| 1 | Searching and Sorting | `01_Searching_Sorting.cpp` |
| 2 | Stack using Linked List – Infix to Postfix and Prefix | `02_Stack_Infix_Postfix_Prefix.cpp` |
| 3 | Circular Queue using Array | `03_Circular_Queue.cpp` |

### Part B – Python

| No. | Practical | File |
|---|---|---|
| 4 | Binary Search Tree | `04_Binary_Search_Tree.py` |
| 5 | Minimum Spanning Tree – Prim's and Kruskal's Algorithms | `05_Graph_MST.py` |
| 6 | Heap Sort | `06_Heap_Sort.py` |
| 7 | Merge Sort for Online Orders | `07_Merge_Sort_Orders.py` |

| 9 | Naive String Matching Algorithm | `09_Naive_String_Matching.py` |

## How to Run

### C++ Programs
Compile using g++:

```bash
g++ filename.cpp -o output
./output
```

### Python Programs
Run using Python:

```bash
python filename.py
```

## Purpose

This repository is created for learning and practising fundamental Data Structures and Algorithms concepts as part of the SPPU Second Year IT curriculum.
